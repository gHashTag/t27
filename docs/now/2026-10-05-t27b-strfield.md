## ConstDecl(str field) lowered (Closes #6323)

- `cli/t27b/src/lower.rs`: a module constant of a struct (or array) type with a `str` at a leaf is now a compile-time aggregate (`Val::A`, one element per field), written into a frame temporary where memory is needed -- the path a constant array of strings already took. `holds_str` looks through struct fields; `store_const` writes struct fields as well as array elements.
