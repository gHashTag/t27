# NOW -- t27b: the remaining [N]T spellings lower like the reference (2026-10-05)

## [T; N], repeats, text lists and [T] slices (Closes #6346)

- `cli/t27b/src/lower.rs` now lowers `[T; N]` and the repeat forms `[v; n]` and `[_]T{a} ** n`. The repeat element is evaluated once, then copied forward by doubling, which matches t27c's `.{ ... } ** n`.
- It also lowers text-list literals, and `[T]` slice parameters given a literal or a local array (t27c's `@constCast(&[_]T{...})` and `slice_locals`).
- What cannot be matched is refused by name: `type [*]T`, `type [K:V]`, `ExprArrayLiteral(repeat to slice | text element | text form | repeat count | to slice)`, and a size mismatch "N elements for `[M]T`". A text element that shadows a module-level name is refused, because Zig rejects the shadow in the reference.
- Module constants are now known before the signature pass, so a spliced `const N` used in an array type resolves.
