# NOW -- One rule, two spellings (2026-09-08)

## One rule, two spellings (Closes #3469)

- Last pass fixed `Trit.pos` and never asked about `TokenKind::KwFn`. It is the **same enum-member reference**, spelled with a path, and it left **917 `X::Y` occurrences in the generated C** across 65 files -- C has no `::` in an expression at all. Errors **13331 → 12420**, **27 files better and none worse**, 4 more translation units compiling clean. `compiler_diagnostics` 43 → **0**, `compiler_lexer` 133 → 3, `igla_race_formal` 393 → 257.
- Both spellings now go through **one helper**, so a change to the naming rule cannot reach one and miss the other. A mutant that disables either call site is killed by the other's tests.
- **The membership test moved from the enum's NAME to its VARIANTS.** 12 corpus sites name a member their enum does not declare (`Trit::TRUE` against `pos`/`neg`/`zero`). Lowering those would emit a constant `gen_c_enum` never wrote -- trading a diagnostic that names the spec's mistake for one that hides it. They stay loud.
- **Predicted 526, delivered 505, and the 21 are accounted for exactly**: they sit inside emitted C *comments* (`/* invariant ... is not a C constant expression: (ErrorCode::Success == 0) */`), which that path prints verbatim rather than through the expression emitter. Those produce no errors. A gap between prediction and outcome is a question, not a rounding error.
- **My own reader over-counted by 9.** `c_error_classes.py` searched for the word `error:`, and clang echoes the offending source line under each message -- so three lines of one spec containing `"error: "` in a *string literal* were counted as errors. Anchored on `file:line:col: error: ` now, with a self-check whose fixture puts the error ON the quoted line; the first version of that fixture put the string on a clean line, passed for the wrong reason, and could not have failed.
- **And I measured a mutant.** After the mutation run I restored `compiler.rs` and did not rebuild, so the tool reported 13120 with `unexpected type name 'Trit'` back at 641 -- the numbers of the mutant that disables the dotted arm. Two of my own instruments disagreed by 700 and the disagreement is what caught it.
