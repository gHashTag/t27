# NOW -- t27b structs (2026-10-04)

## t27b: structs, field access, pointers and struct results (Refs #5977)

- t27b now lowers struct declarations, named and anonymous struct literals, field defaults, field reads and writes (including nested and compound `+=`), `&x`, `p.*`, `*T` and `*const T`, field access through a pointer, struct parameters, and struct results. Module-level struct constants go into read-only data, and their scalar fields fold to constants.
- Structs live in memory, never in registers:
  - a local or a temporary gets a frame slot;
  - a parameter is the caller's memory, passed by address and never written;
  - a struct result is built through a hidden last pointer parameter.
- A function that takes or returns a struct uses this internal convention, so `t27b build` does not export it, and says so.
- Layout follows the C rules and is computed on first use, as in Zig: an unused struct with an unsupported field rejects nothing.
- Rejections are precise: a missing, unknown or duplicate field, a literal with no result type, a write through a constant, `==` on structs, a struct that contains itself, and a generic struct.
- New IR expression `Seq`: stores, then a value. It builds a struct temporary at the exact point where an argument is evaluated. The random differential generator emits it with temporaries live around it.
- Corpus: 47 -> 70 files passing, 0 JIT/interpreter mismatches.

  - Two files time out at a load average near 780: the t27c front end alone takes 10 s to parse them.
