# NOW -- Writes that landed in a copy (2026-09-08)

## Writes that landed in a copy (Closes #3402)

- gen-rust rendered every `[]T` parameter as `Vec<T>` -- by value, no `mut` -- and then emitted `buf[i] = x` into it. Measured on master: **189** specs declare a slice parameter, **174** parse, **23** emit Rust that assigns into one, and **0 of the 23 compile**. The path is uniformly broken, so this change cannot regress a working case: there are none.
- Two defects, and the second is worse. It does not compile (E0382/E0596); and had it compiled, the writes would have landed in a moved copy and the caller would see nothing. A plausible future fix -- adding `mut` to the binding -- would have made it compile and left it silently wrong. The C backend passes a pointer and Verilog gives the caller its writes, so Rust was the column disagreeing with the other three.
- A per-function scan is not enough: `char_to_trits` never assigns into its own `trits`, it hands it to `byte_to_trits`, which does. Marking only direct writers gives caller `Vec<i32>` and callee `&mut [i32]`, and the call between them is E0308. `collect_written_slice_params` iterates to a fixpoint over calls, following bare identifiers only.
- Worth, measured over all 650 specs: move/borrow errors fall **33 files / 143 diagnostics -> 14 / 45**. rustc acceptance is unchanged at **430 of 650**, and 312 of those contain a function -- the second consecutive fix whose acceptance delta is zero, because a rejected file carries four or five error families and not one.
- 158 files' output changed, 29 lost an error class and 16 gained one. Every newly reported diagnostic was checked line by line: **60 REVEALED, 0 INTRODUCED** -- each blames a line byte-identical in both outputs, reached only because an earlier name-resolution error no longer aborts the compile. The one genuinely introduced error found mid-way (`[]const u8` renders `Vec<const>`, and `&[const]` is not a type) was fixed by requiring the element to be a plausible type name.
- Mutation-checked: disabling the inductive step of the fixpoint fails `an_out_parameter_threaded_through_a_call_is_still_an_out_parameter` and leaves the base-case test green, so the two tests are independent.
