# NOW -- t27b: the multi-object for loop (2026-10-05)

## StmtFor(multi-object) (Closes #6458)

- `for (xs, ys, ...) |x, y, ...|` over arrays, slices and strings lowers to one hidden index over every object, each iterable evaluated once, in order, as Zig does.
- Lengths that differ at run time trap before the first iteration with the new trap kind `ForLength` ("for loop over objects with non-equal lengths", Zig's safety panic); two different comptime lengths are refused, because the reference is BLOCKED on them ("non-matching for loop lengths").
- The single-object loop now goes through the same `for_objects` code. Code in the new submodule `cli/t27b/src/lower/formulti.rs`; tests in `cli/t27b/tests/formulti.rs`, each source run under `t27c test-report` first (4 pass, 1 fail there and here).
