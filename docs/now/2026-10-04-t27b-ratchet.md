- `tri t27b ratchet [--run <path|url>] [--ledger <path>] [--bless] [--json]`: a stdlib Python checker. It reports UNEXPECTED FAILURE, UNEXPECTED PASS, UNLISTED, STALE, OVER CAP and BAD REASON as red (exit 1), and MOVED, UNJUDGED and VACUITY MEASURED as info only. It is not part of `t27b corpus`, because reference verdicts are only merged by `lab.py`, after the corpus has returned.
- `t27b test --check` prints the number of runtime asserts the interpreter executed (an assert whose condition is not a constant). `t27b corpus` labels a pass with 0 as `pass_vacuous` and writes `asserts` in every JSON record.
- The ledger says `pass_vacuous: null` and not 0, because the source run predates counting. The first counted run reports VACUITY MEASURED, which is info only, and needs one `--bless`.
- `lab.py` runs the clone's own checker against the clone's own ledger and records `steps.ratchet` in latest.json. `tri t27b doctor` reports LAB-RATCHET when that step is red. The lab is not redeployed by this PR.
