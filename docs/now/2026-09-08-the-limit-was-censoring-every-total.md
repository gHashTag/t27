## The limit was censoring every total (Closes #3448)

- **Every error count I published this session was a floor.** Clang stops at `-ferror-limit=20` per file by default, and **141 files reach it**. The corpus emits **15133** errors, not the 3849 I have been reporting. The per-file splits were sound because they were counted per file; the totals were not. Re-measured without the limit, the previous pass's change moved **15188 → 15133 (−55)**, not the −24 published. The number was never wrong about direction and was wrong about size, and I only found it because a fix that removed real errors showed a **zero** delta -- three files that each sat exactly at 20 before and after.
- The fix itself is W583 in a position its own repair never reached. `var x : [4]GF16;` emitted `GF16 x[4];` -- `use of undeclared identifier` -- while the same element is `uint16_t` in a parameter and in a struct field. The local path gated on `is_primitive`, and the note retiring that gate sits **two hundred lines below in the same file**, naming `f32`, `f64`, `str`, `string` and `gf16` as the types it swallowed.
- Two more in the same eight lines: `var x : []u8;` emitted `uint8_t x[];`, which is not a definition, and `var x : []const u8;` emitted `const u8* x` because the qualifier lives inside the element text. Measured: **15133 → 15126**, three files better, **zero worse**.
- **The first version of the slice repair was wrong and the corpus said so.** Rewriting every `[]T` local to a pointer broke `T x[] = {…}`, which is legal C and takes its size from the initialiser list: +5 errors and nothing better, in the one file carrying the shape. The condition `size.is_empty() && node.children.is_empty()` is that measurement, kept as code.
- The table's fourth position measured the wrong thing first, too. `var x : T;` with no initialiser: C and Rust declare it, Zig and Verilog emit **nothing** -- so the probe was reading their dead-code removal rather than their lowering. Initialising from a parameter of the same type fixed it, and the self-check now covers all four positions.
