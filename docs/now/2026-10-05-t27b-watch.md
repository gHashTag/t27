# NOW -- tri t27b watch: a stacked PR chain merged as steward.t27 decides (2026-10-05)

## tri t27b watch (Closes #6285)

- `tri t27b watch N...` walks a t27b PR stack in order: merge on READY (`gh pr merge --merge` only), wait on WAIT, retarget to master and bring master in with `gh pr update-branch` once the stacked parent merged, stop on RED, CONFLICT or BLOCKED, skip a closed PR.
- The decision is `watch_action(verdict, parent)` in `specs/tri/t27b/steward.t27` (10 new tests, 91 in all); `gen/c/tri/t27b/steward.c` is `t27c gen-c` output from the t27c lab, sha256 75f05574..., and the lab's `test-report` passes 91 of 91.
- The parent's state is read from GitHub on every look (`gh pr list --head <base> --state all`). An unreadable read is no action and a second look, never a guessed retarget: a throwaway watcher skipped the retarget of #6254 that way on 2026-10-04 (skill slip Q33).
- `--fixture DIR` never reaches GitHub; `--once` and `--dry-run` print the action without running it. A mutation of the generated C (`parent == 1` -> `parent == 9`) fails three checks across the two CI tests.
