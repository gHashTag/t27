# NOW -- the GitHub App (t27-bees) as the Queen's front door, in .t27

## specs/queen/app.t27 (Closes #7682)

- `app_reaction` maps a GitHub webhook to REGISTER, UNREGISTER, REVIEW, FORGET, COMMAND, QUOTA or
  IGNORE. The Queen never answers a bot (no loops) and never acts on a repository she does not
  serve.
- Free tier: 200 reviews a day per installation for public repositories, 30 for private ones
  (`free_reviews_left`). A diff over 4000 lines is summarized, not reviewed line by line.
- One review per pull request head (`review_wanted`) unless a person asks again.
  `command_of` reads `@t27-bees review | summary | help | pause | resume`.
- Tests: 7 of 7. `tri mutate spec` kills 64 of 66 mutants; the 2 survivors are equivalent, and the
  card says why.
- Runs as generated code: `t27c gen-c` + `zig cc --target=wasm32-wasi` gives a 1637-byte module
  with no imports, and its functions answer the test vectors when called from Bun.
