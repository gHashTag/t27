## tri t27b reduce: ddmin over declarations, statements, expressions (Closes #6445)

- `tri t27b reduce SPEC [--family X | --disagree]` runs delta debugging over declarations, then statements, then expressions. Every candidate must pass `t27c parse`, so no time goes on files that do not parse.
- Every decision lives in `specs/tri/t27b/reduce.t27` (13 tests and one invariant): whether a candidate is interesting, the chunk arithmetic, the level order, the budget and the goal. `gen/c/tri/t27b/reduce.c` is `t27c gen-c` output, byte-identical to the lab's master t27c. The Python only does I/O and is listed in `tools/policy/foreign-exceptions.txt` (owner-approved-foreign; debt #6198).
- Reference guard: the reference is checked first. A candidate whose reference (`t27c test-report`) does not pass is never kept, and neither is one where the reference runs no test. A spec that fails the guard is refused with `REFERENCE-NOT-PASS` and exit 1, because it is a reference bug (Q38), not a lane.
- `specs/isa/ternary_encoding.t27`, family `ExprBinary(value ignored) statement`: reduced from 360 to 9 lines in 639 candidates (98 reference runs). Fixture: `cli/t27b/tests/reduced/exprbinary_value_ignored_statement.t27`. Its header records the origin, and `t27b corpus --reference-cache` is reused.
- `tri t27b next` adds a `repro:` line under each lane with a fixture (`repro` in `--json`), so rank 1 now links its repro.
