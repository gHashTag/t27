# NOW -- t27b compiles integer casts natively (2026-10-04)

`x as T` between integer types was the construct that, alone, kept the most
specs out of t27b: 18 files needed nothing else.

## Integer casts (Refs #5977)

- `ExprCast` between the integer types and from `bool` now lowers to native
  AArch64. Casts to or from a float and casts to `bool` are still rejected.
- A lossless cast widens. A cast from `bool` gives 0 or 1. An unsigned cast to a
  narrower unsigned type truncates, like Zig's `@truncate`.
- Every other narrowing is checked, like Zig's `@intCast`: a value outside the
  target type traps at a new site kind, `brk #7` in an object file.
- With wrap overflow every narrowing truncates. A constant operand is folded,
  and a literal that does not fit is rejected.
- The corpus goes from 36 to 54 passing files (109 tests), with 0 failing and
  0 JIT/interpreter mismatches.
- The differential generator now emits casts and bool widening, and a new test
  runs every integer cast at its edge values, checked and truncating. Both
  report 0 mismatches.
