## `t27-bees` GitHub App, and a merger that counts only its approval (Closes #5547)

- Owner's decision of 2026-10-02: reviewer bees approve under their OWN identity, not the owner's account `gHashTag`. GitHub refuses self-approval and `gHashTag` authors every bee pull request, so the reviewer bee on #5526 could only leave `COMMENTED`; the merger, which needs APPROVED, could never fire for a bee pull request.
- `tools/bees/`: `manifest.json` (private app, no webhook; pull requests write, issues write, contents/checks/metadata read), `bee-app create` (manifest flow on 127.0.0.1:8727, `POST /app-manifests/{code}/conversions`, key to `~/.config/t27-bees/` mode 600, app id and key PATH to the Keychain; `client_secret` and `webhook_secret` dropped), and `bee-token` (RS256 JWT signed by `openssl`, traded for a one-hour installation token scoped to one repository). Standard library only.
- `.github/workflows/auto-merge-ready-prs.yml`: the approval that counts is the LATEST decisive review by `vars.BEE_REVIEWER_LOGIN` (default `t27-bees[bot]`), it must be APPROVED, of the head SHA, and submitted after the head arrived (the push-time logic of #5526). The `bee-reviewed` label must also be applied by that login. A login not shaped `<slug>[bot]` merges nothing; an unreadable review list skips the pull request.
- `bees.py self-test`: 33 checks with a throwaway key, including a tampered-payload negative control; mutations (ten-minute JWT window widened, repository scoping removed) each turn it red. A real call with a throwaway key reached GitHub and got `404 Integration not found`, so the JWT shape is accepted.
- `merger_gate_selftest.py` runs the workflow's own `Find ready PRs` script against a stub `gh` whose `--jq` is real `jq`: 11 scenarios pass on this workflow; the same scenarios against master's workflow fail 9 of 11 (owner-only approval, stale SHA, revoked approval, owner-applied label all merged).
- Not done here, owner's clicks: creating and installing the app, setting `BEE_REVIEWER_LOGIN`. Until then the merger merges nothing, which is the intended fail-closed state. Steps: `tools/bees/README.md`.
