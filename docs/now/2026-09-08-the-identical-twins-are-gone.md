## The identical twins are gone (Closes #3481)

- Last pass made a blind gate see 341 duplicated names and measured that 174 of the blocks were byte-identical twins. **188 removed** -- 29 specs, 838 lines deleted, **0 inserted**. Errors **12 071 -> 11 780**, `redefinition of 'X'` **365 -> 204**, the ratchet **30 specs / 341 names -> 27 / 172**. 188 rather than 174 because the estimate came from a cruder extractor that mis-parsed the two brace-form specs.
- **The decisive control was a before/after diff of the generated C**, not of the specs. Across all 582 headers: **29 changed** -- exactly the specs edited -- 1203 removed lines inside a `void test_*(void)` region, 183 blanks beside one, 27 old `printf("All %d tests passed")` lines, and **0 removed from anywhere else**; 29 added, all the same summary line with a smaller count.
- **Reading one spec's diff by hand, before applying anything, found the real bug.** `invariant` was not in the set of tokens that end a Gherkin-form block, so a duplicate test ran on through the invariant that followed it -- deleting the test would have deleted a live declaration. No aggregate would have shown that; the corpus totals would have improved either way.
- **My own round-trip control was measuring its own join.** It compared the re-assembled file as a STRING, and joining pieces with newlines inserts one wherever a piece is empty -- which is wherever two blocks abut. It refused 49 specs for that reason. Comparing line lists instead: 0 refused.
- **And the counting control's safe set had to be measured.** In the brace form a test body legitimately contains `const provider = ...`, `type = ContentType::Text,` (a struct field) and `invariant cov == 100;` (an assertion); counting those anywhere refuses two specs for nothing. Measured: `struct`, `module`, `impl`, `use`, `bench` never appear inside a test body at any indentation, and `invariant`/`fn`/`const`/`type`/`enum` never at column zero.
- What is left is **172 duplicated names whose bodies DIFFER** -- a second test wanting its own name, or a revision of the first, the same shape as `adamw.t27`. A script cannot choose between them, and the ratchet names every spec that holds one.
