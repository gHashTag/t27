## The committed steward C is checked against master's t27c, not by hand (Closes #6231)

- `gen/c/tri/t27b/steward.c` is `t27c gen-c specs/tri/t27b/steward.t27` (L2). t27c runs on the Railway lab t27c-lab, never on the Mac, so each t27b PR proved byte-identity by a hand-run `railway ssh`.
- `tri t27b gen-check [--spec] [--gen] [--json]` sends the local spec to the lab as base64, runs the lab's `/data/target/release/t27c gen-c` in a scratch dir under /tmp that it removes, and compares sha256 and length: `SAME <sha12>` exit 0, `DIFFERS lab <sha12> local <sha12>` exit 1, `UNREACHABLE <reason>` exit 2.
- A second line prints the lab binary's path, mtime and sha and the lab checkout's commit; `STALE?` when the binary is older than the checkout.
- One kernel argument is capped at 128 KiB: an 80 KB command went through, a 133 KB one came back "Argument list too long". The spec is sent in 64000-character chunks; steward.t27 fits in one.
