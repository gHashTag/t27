## 3. VCD import path

Generate a minimal 25 MHz scalar VCD:

```bash
python3 - <<'PY'
with open('/tmp/tri_cclk_valid.vcd','w') as f:
    f.write("$date today $end\n")
    f.write("$version tri test $end\n")
    f.write("$timescale 100 ps $end\n")
    f.write("$scope module top $end\n")
    f.write("$var wire 1 ! cclk $end\n")
    f.write("$upscope $end\n")
    f.write("$enddefinitions $end\n")
    f.write("$dumpvars\n")
    f.write("0!\n")
    f.write("$end\n")
    period_ps = 400  # 40 ns = 25 MHz
    half = period_ps // 2
    t = 0
    for i in range(40):
        t += half
        val = '1' if i % 2 == 0 else '0'

PY
```
