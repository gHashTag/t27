# Wave Loop 397 Report — SPI boot root-cause closure

**Issue:** #1294  
**Branch:** `wave-loop-397` → `trinity-rust-rings`  
**Date:** 2026-07-06  

## Goal

Confirm or rule out the remaining high-priority hypothesis **H1 (cold-POR
mode-pin sampling)** for the QMTech Wukong V1 / XC7A200T-FGG676-1 boot-from-flash
failure. If H1 was ruled out, scope **H2 (CCLK/SPI-startup timing)** for W398.

## What was delivered

1. **CLI hardening**
   - `tri fpga stat --pre-jtag-reset --repeat N` for multiple power-on STAT
     samples.
   - `tri fpga boot-log <bit>` guided cold-POR experiment with printed
     decision tree.
   - `tri fpga smoke-gate` board-less check (`bit-config` + yosys synthesis).
2. **CI hardening**
   - Added Phase 3c FPGA board-less smoke gate to the in-runner conformance
     suite (`bootstrap/src/suite.rs`).
3. **Documentation**
   - Hardened cold-POR protocol and decision tree in `fpga/HARDWARE_SSOT.md`.
   - Deprecated stale `fpga/diagnostics/jtag_wiring.md` and redirected to the
     SSOT.
4. **Evidence gathering**
   - Board detection OK (`idcode 0x3636093`).
   - Initial STAT showed `DONE=1` (prior configured state).
   - After JTAG reset, STAT=`0x5000190C`, `MODE=0b001`, `DONE=0`,
     `CRC_ERROR=0`, `ID_ERROR=0`.
   - SRAM load of the same bitstream succeeds (`done 1`).
   - Flash round-trip verify passes (9,730,548 bytes match).

## Key finding

**H1 (mode-pin sampling) is likely ruled out.** After a JTAG reset the FPGA
samples the correct **Master SPI x1** mode (`MODE=0b001`) but still fails to
complete configuration. This points to **H2 (CCLK/SPI-startup timing or flash
state after reset)** as the leading remaining hypothesis.

A true cold power-cycle still requires user assistance; the exact protocol is
documented in `docs/reports/FPGA_LOOP_EVIDENCE_2026-07-07.md` and
`fpga/HARDWARE_SSOT.md` §3.1.
