# План выполнения Wave Loop 136

## Цель
Выполнить стандартный цикл расширения тестового покрытия и обновления конкурентной разведки в рамках IGLA CODER / IGLA RACE.

## Этапы выполнения

### 1. Аудит слабых мест
- Запустить `grep` для подсчета `test` и `bench` блоков во всех `.t27` файлах `specs/igla/`.
- Определить 8 спек с наименьшим покрытием, исключив те, что обрабатывались в W135 (исключение ротации).

### 2. Исследование конкурентов
- Проанализировать `docs/COMPETITIVE_POSITIONING.md`.
- Выявить документированных, но еще не добавленных в `benchmark.t27` конкурентов.
- Выбрать 2 конкурента высокого приоритета.

### 3. Декомпозиция задач
- Распределить 16 новых тестов (по 2 на спеку) по выбранным 8 файлам.
- Описать 2 новых конкурента для добавления в `benchmark.t27`.

### 4. Реализация
- Добавить `test` блоки в 8 целевых спек.
- Добавить функции конкурентов и тесты на их корректность в `benchmark.t27`.
- Обновить `docs/COMPETITIVE_POSITIONING.md`.

### 5. Верификация
- Перегенерировать `seal` для всех затронутых файлов.
- Запустить `./scripts/tri suite --repo-root .`.
- Убедиться в отсутствии регрессий (ожидаемый результат: 565/565 PASS).

### 6. Завершение
- Создать отчет (`WAVE_LOOP_136_REPORT.md`).
- Сформировать варианты сотрудничества (`WAVE_LOOP_136_COOPERATION.md`).
- Зафиксировать изменения коммитом с `Closes #1060`.
- Обновить память проекта (`wave-loop-136.md`).

## Критерии приемки
- [ ] 16 новых тестов добавлены.
- [ ] 2 новых конкурента интегрированы.
- [ ] Все seal совпадают.
- [ ] Suite проходит без ошибок (565/565).
- [ ] Отчет и варианты сотрудничества созданы.
