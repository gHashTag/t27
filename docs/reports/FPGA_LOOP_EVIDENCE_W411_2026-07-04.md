## 1. Physical state at start of W411

The bench blockers from W410 persist:

- **P12 capture blocker:** P12 is not wired to a logic-analyzer channel. A live
  `tri fpga measure-cclk --live` capture is still impossible.
- **DLC10 cable blocker:** `dlc10 idcode` still fails with
  "DLC10 cable not found (VID=0x03FD)", so flash programming and
  `tri fpga cclk-sweep` are impossible.

Because of this, **Variant A** (real P12 + OSCFSEL 6/7 boot) and **Variant B**
(relay CI gate, which needs the cable to verify the state machine) are
blocked. W411 delivered **Variant C alone**: auto-proof tooling and a PVT-margin
layer in the formal model.

## 2. Auto-proof tooling: `tri fpga measured-to-lean`

### Synthetic fixture → JSON

```bash
$ cat /tmp/measured.json
{
  "freq_hz": 2495000,
  "duty_pct": 50.0,
  "sck_low_ns": 200,
  "sck_high_ns": 200,
  "source": "synthetic (10000000 Hz samplerate)"

```

### JSON → Lean theorem

```bash
$ cargo run -p tri -- fpga measured-to-lean --file /tmp/measured.json --out /tmp/generated.lean

  decide
```
