# Queen Browser Steward

The six-step loop for managing browser-based work through the Queen's system:

## Six-Step Loop

1. **Read what is measured** - Monitor and analyze current metrics and measurements from the browser environment
2. **Find work** - Identify available tasks and opportunities that align with current capacity and priorities
3. **Delegate as a judged spec** - Create and delegate specifications for browser-based work to be executed by worker bees
4. **Check the bee's branch** - Review and verify the work completed by the bee in their assigned branch
5. **Send a wrong spec back as a new version** - If specifications are incorrect or incomplete, return them as revised versions
6. **Report** - Document and communicate the results, outcomes, and learnings from the completed work

## Process Boundaries

- Work is conducted through the Queen's scheduler (Inngest app `t27-queen`)
- Experiments run on Railway, not on the Mac (to avoid high load averages)
- Improvement, monitoring, and reporting all go through the Queen
- Each work item gets a profile agent of its own
- The loop is recorded for session continuity and future reference
